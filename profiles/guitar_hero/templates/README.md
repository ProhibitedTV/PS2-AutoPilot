# Guitar Hero template namespace

Put cropped/full-frame PNG evidence for the original Guitar Hero here. The profile uses
semantic substrings in the filename, so useful names include:

- `gh_title_press_start.png`
- `gh_save_prompt_yes_selected.png`
- `gh_main_menu_career_selected.png`
- `gh_main_menu_quick_play_selected.png`
- `gh_setlist_song_selected.png`
- `gh_difficulty_easy_selected.png`
- `gh_difficulty_medium_selected.png`
- `gh_difficulty_hard_selected.png`
- `gh_difficulty_expert_selected.png`
- `gh_loading.png`
- `gh_cutscene_venue.png`
- `gh_note_highway_gameplay.png`
- `gh_results.png`
- `gh_song_failed.png`
- `gh_high_score_initials.png`

Templates are advisory evidence layered over normalized image semantics. Do not capture
animated frames as broad menu templates and do not lower the global threshold to make a
single weak capture pass.
